# Git

## Skills

Use `/commit` to commit changes.

## Conventions

* Branch off `master`; do not commit directly to `master`.
* Write commit and PR subjects in imperative English, wrap code symbols in
  backticks, and append a trailing `(#issue)` when a related issue exists.
* Do not append `Co-Authored-By`.
* Never push or change the git remote without explicit human approval
  (see [safety-guards.md](safety-guards.md)).
